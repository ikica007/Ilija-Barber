# Barber Ilija — Premium Barbershop

Zvanična web prezentacija za **Barber Ilija** salon u Crnoj Gori. Web sajt kombinuje moderan, minimalistički dizajn u tamnim tonovima, besprekorno korisničko iskustvo, dvojezičnu podršku (Crnogorski / Engleski), interaktivni cenovnik po berberima, priču o brendu i integrisani intro video.

---

## 💈 O Projektu

- **Moderan & Minimalistički Dizajn**: Tamna estetika sa prefinjenim zlatno-narandžastim akcentima i glatkim prelazima.
- **Multilanguage (SR / EN)**: Puna podrška za crnogorski i engleski jezik uz jednostavnu promenu u navigaciji.
- **Berberi & Usluge**: Detaljan pregled timova i usluga (Ilija - Master Barber, Marko - Senior Barber, Nikola - Senior Barber) sa cenama, trajanjem i opisima tretmana.
- **Naša Priča**: Interaktivna hronika puta od zanata do prepoznatljivog brenda sa arhivskim fotografijama i priznanjima.
- **Galerija**: Prikaz najnovijih radova, fade prelaza i stilizovanja.
- **Kontakt & Rezervacije**: Prikaz lokacije, radnog vremena i brza rezervacija putem telefona i Instagrama.

## 🚀 Pokretanje Projekta Lokalno

### Preduslovi
- [Node.js](https://nodejs.org/) (verzija 18+ preporučena)
- `npm` ili `bun` / `yarn` / `pnpm`

### Koraci

1. **Kloniranje skladišta:**
   ```bash
   git clone https://github.com/ikica007/Ilija-Barber.git
   cd Ilija-Barber
   ```

2. **Instalacija zavisnosti:**
   ```bash
   npm install
   ```

3. **Pokretanje razvojnog servera:**
   ```bash
   npm run dev
   ```
   Aplikacija će biti dostupna na `http://localhost:3000`.

4. **Build za produkciju:**
   ```bash
   npm run build
   ```
   Kompajlirani fajlovi se nalaze u `dist/` direktorijumu.

5. **Pregled produkcijskog builda:**
   ```bash
   npm run preview
   ```
